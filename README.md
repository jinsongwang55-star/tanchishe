# 霓虹贪吃蛇 · Neon Snake

单文件 HTML5 / Canvas 贪吃蛇游戏，零依赖。直接打开 `snake-game.html` 即可游玩。

## 玩法

- **6 种模式**：经典 / 穿墙 / 障碍 / 极速 / 迷宫 / 混沌（切换后点「重新开始」生效）
- **5 种道具**：🚀 疾走、🐢 缓速、✂️ 缩短、👻 幽灵（穿墙且不自咬）、✖️ 双倍分数
- **两种食物**：普通果实 +10 分；黄金果实 +50 分（限时刷新）
- **成长曲线**：每吃 5 个升级，速度递增；最高分按模式分别记录在浏览器本地

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / `W` `A` `S` `D` |
| 暂停 | `空格` / `P` |
| 重开 | `R` |
| 触屏 | 在棋盘上滑动转向 |

## 运行

直接双击 `snake-game.html`，或用任意静态服务器托管该文件即可。

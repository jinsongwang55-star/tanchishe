# 星灵消消乐 · 魔法阵传奇

一个纯前端、零依赖的三消（Match-3）小游戏，使用原生 HTML + CSS + JavaScript 构建，支持 5 种玩法模式、30 个闯关关卡、特殊糖果合成、多类障碍与 7 种道具。移动端优先，可直接部署到 GitHub Pages。

---

## 一、设计语言

### 1. 视觉风格

整体走「魔法糖果幻境」路线：**粉紫蓝渐变的梦幻底色 + 毛玻璃卡片 + 圆润糖果造型 + 高频轻快动效**，营造休闲、治愈、轻巧的游玩氛围。图形全部使用 Emoji 作为游戏元素，无需任何图片资源，加载即玩。

### 2. 色彩系统

设计令牌定义在 `style.css` 的 `:root` 中：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--pink` | `#ff5aa8` | 主色 / 标题渐变 / 主按钮 |
| `--purple` | `#8b5cf6` | 副主色 / 强调 / 星级 |
| `--cyan` | `#22d3ee` | 点缀 / 冰冻光晕 |
| `--mint` | `#34d399` | 点缀 |
| `--gold` | `#ffb400` | 星级 / 锁链光晕 / 数值 |
| `--text` | `#4c2a86` | 主文字（深紫） |
| `--muted` | `#9a7bc0` | 次要文字（浅紫） |
| `--panel` | `rgba(255,255,255,.62)` | 毛玻璃面板 |
| `--shadow` | `0 8px 24px rgba(190,120,255,.18)` | 柔和紫阴影 |

**背景**：三层渐变叠加（径向高光 + 粉→紫→青的 150° 斜向线性渐变）。

**6 种糖果色**（`game.js` 中 `GEM_COLORS`）：

| 🍓 | 🍊 | 🍇 | 🍏 | 🍋 | 🫐 |
| --- | --- | --- | --- | --- | --- |
| `#ff5a76` | `#ff9f43` | `#a55eea` | `#2ecc71` | `#feca57` | `#4b7bec` |

**特殊糖果配色**：火箭青 `#7ad0ff`、炸弹红 `#ff6b6b`、彩虹白 `#ffffff`。

### 3. 字体与排版

- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`（系统字体，零加载成本）。
- 标题 `h1`：30px / 900 字重 / 2px 字距，粉紫青渐变文字 + 呼吸光晕动画。
- 数据使用 `font-variant-numeric: tabular-nums`，数字对齐不跳动。
- 分数回弹采用 `requestAnimationFrame` 缓动（cubic-ease-out）滚动。

### 4. 形状与空间

- 大圆角：卡片 `20–26px`、按钮 `999px`（胶囊）、糖果 `24%`。
- 布局宽度 `min(96vw, 520px)`，居中单列，卡片间距 `8–12px`。
- 棋盘 `aspect-ratio: 1/1`，糖果尺寸由 `--cell` 变量动态计算（`board 宽度 / 列数`），自适应任意屏幕。
- 毛玻璃：`backdrop-filter: blur(8px)` 贯穿面板、按钮、道具、目标胶囊。

### 5. 动效与反馈

动效以「轻快、Q 弹」为核心，大量使用 `cubic-bezier(.3,1.2~1.5,.4,1)` 回弹曲线：

- 背景漂浮光斑 `floaty`、标题呼吸光晕 `titleGlow`
- 糖果交换位移动画、消除粒子 `pop`、得分飘字 `floatup`、冲击波 `wave`
- 特殊合成横幅 `bannerpop`、屏幕震动 `screenshake`、宝石弹入 `dropIn`
- 命中时提亮 `peel`、消除前缩放消失 `poof`、拖拽跟手 `scale 1.12`
- 双层障碍、特殊糖果均有分色光晕

### 6. 音效与氛围

全部音效使用 **Web Audio API 实时合成**，无任何音频文件：

- 消除音按连击数升高音高；炸弹/火箭/彩虹各有专属扫频与噪声爆发
- 背景音乐：C 大调 I–IV–V–I 进行的主旋律（跳音 + 低音伴奏 + 泛音点缀）
- 支持一键静音（状态持久化到 localStorage）

## 二、技术架构

| 项 | 说明 |
| --- | --- |
| 技术栈 | 原生 HTML5 + CSS3 + ES2019+（无框架、无构建、无第三方依赖） |
| 数据模型 | `grid`（10×10 二维数组）+ `els`（`Map<id, DOM>`）弱映射 |
| 渲染策略 | 增量同步：`render()` 对比 `seen` 集合，新增/复用/删除 DOM，避免整板重建 |
| 动画 | CSS Keyframes + 少量 `requestAnimationFrame` + `async/await` 流程控制 |
| 存储 | `localStorage`（安全封装，隐私模式下静默降级） |
| 输入 | Pointer Events（`pointerdown/move/up/cancel`），6px 死区判定主轴，rAF 合并高频 move |
| 部署 | 纯静态文件，GitHub Pages 一键托管 |

### 文件结构

```
match3-game/
├── index.html    页面结构、DOM 骨架、弹窗与遮罩
├── style.css     设计令牌、视觉样式、全部动效与响应式
└── game.js       全部游戏逻辑（配置、引擎、AI 提示、音效、UI）
```

## 三、玩法系统

### 1. 五大模式

| 模式 | 胜利条件 | 说明 |
| --- | --- | --- |
| 经典模式 | 26 步内达到 4000 分 | 步数冲刺 |
| 闯关模式 | 达成关卡目标（或连击达 200） | 30 关配置驱动 |
| 收集模式 | 24 步内集齐指定糖果 | 随机 4 种糖果 |
| 挑战模式 | 达成递增目标 | 三重关卡，障碍随关递增 |
| 无限模式 | 无结束 | 无限步数，连击掉落道具 |

### 2. 特殊糖果合成

| 消除形状 | 产物 | 效果 |
| --- | --- | --- |
| 4 连 | 🚀 火箭 | 横/竖清除一整排（按方向） |
| T / L 形交叉 | 💣 炸弹 | 引爆 3×3 区域 |
| 5 连 | 🌈 彩虹 | 清除场上最多的同色糖果 |

**特殊互碰**：火箭×炸弹、火箭×火箭、彩虹×任意（同色全清）、双彩虹（全场清空）触发更大范围连锁。

### 3. 障碍系统

| 障碍 | 图标 | 机制 |
| --- | --- | --- |
| 冰冻 | ❄️ / 🧊 | 1–2 层，命中掉层不消失 |
| 锁链 | 🔒 / ⛓️ | 1–2 层，命中掉层不消失 |
| 陨石 | 🪨 | 不可移动、不可消除，只阻挡 |
| 巧克力 | 🍫 | 清障目标之一 |

被冰冻/锁链锁住的糖果不可交换。

### 4. 道具系统（7 种）

| 道具 | 效果 |
| --- | --- |
| 🔨 爆破锤 | 清除任意单格 / 障碍 |
| 💣 炸弹 | 引爆 3×3 |
| 🎯 瞄准火箭 | 点选糖果变为火箭 |
| 🌈 彩虹球 | 点选糖果变为彩虹 |
| ➕ 加步数 | 步数 +5（闯关/无限模式禁用） |
| 🔄 洗牌 | 重排棋盘 |
| ✨ 双倍分数 | 15 秒内得分 ×2 |

初始每种 2 个；消除规模大或连击高时概率掉落。道具使用有粒子、冲击波、占景式光标等华丽反馈。

### 5. 连击与连锁

消除的 `resolve()` 循环内每次下落重判都计为一次连击（`combo`）。同色相邻方块有衰减概率连带引爆（相邻 50%、隔层 18%），形成链式扩散。**闯关模式下，本局最高连击达 200 直接判定通关**（`peakCombo` 全局记录）。

## 四、关卡设计

30 关配置集中在 `game.js` 的 `LEVELS` 数组，分 6 个阶段（每阶段 5 关）：

| 阶段 | 名称 | 关卡 | 主题 |
| --- | --- | --- | --- |
| ① | 新手村 | 1–5 | 分数 / 冰 / 收集 / 锁 |
| ② | 特殊合成教学 | 6–10 | 火箭 / 炸弹 / 收集 / 清冰 / 彩虹 |
| ③ | 障碍组合 | 11–15 | 锁+陨石 / 双层冰 / 混合 / 合成 / 冰锁夹击 |
| ④ | 压力测试 | 16–20 | 高分 / 三重收集 / 深冰 / 缤纷合成 / 三线作战 |
| ⑤ | 高手冲刺 | 21–25 | 荆棘 / 四色 / 武库 / 冰封 / 终极混战 |
| ⑥ | 大师殿堂 | 26–30 | 万分 / 彩弹 / 钢铁壁垒 / 王者试炼 / 终极 BOSS |

**关卡配置字段**：

```js
{ name, type, target, moves, colors, collect, craft, clear,
  ice, iceLv, lock, lockLv, stone, choco }
```

- `type`：`score`（分数）/ `collect`（收集）/ `clear`（清障）/ `craft`（合成）/ `mixed`（混合）
- `colors`：本关可用糖果种类数（越少越难出特殊合成）
- 收集目标糖果类型会被**强制纳入颜色池**，避免出现无法生成的死局

**星级规则**：2 星 = 剩余步数 ≥ 30%、3 星 = 剩余步数 ≥ 50%。通关解锁下一关，星数与进度持久化。

## 五、运行方式

### 本地运行

```bash
cd match3-game
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

> 也可直接双击 `index.html`，但建议通过 HTTP 服务运行以确保 localStorage 正常工作。

### 在线部署

推送到 GitHub 仓库 `main` 分支后，在仓库 Settings → Pages 中选择 `main` 分支根目录，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 六、核心规则速查

- 拖动交换相邻糖果，凑成 **3 个及以上同色**即消除。
- 越大的消除形态合成越强的特殊糖果；特殊糖果互碰触发范围爆发。
- 每次消除按 `消除格数 × 10 × 连击数` 计分，连击越高分数滚雪球。
- 棋盘无可行组合时自动洗牌；静止 1 秒自动提示下一步。
- 移动端支持触控拖动，带震动反馈（`navigator.vibrate`）。
